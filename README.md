# こころより | 悩み相談サービス LP

「話すことで、心が軽くなる。」をコンセプトに、共感と傾聴を届ける悩み相談サービスのランディングページです。HTML / CSS のみで構築しており、サーバーやビルドツールは不要です。

## 構成

- ヒーロー（メインビジュアル + キャッチコピー + CTA）
- サービスの 4 つの特徴
- こんなお悩みありませんか？（6 ケース）
- 私たちの約束（共感と傾聴）
- ご利用の流れ（4 ステップ）
- 料金プラン（3 プラン）
- お客様の声
- よくあるご質問
- お問い合わせフォーム
- フッター + 固定 CTA

## 使い方

`index.html` をブラウザで開くだけで表示されます。
