# シンプルアラーム

ブラウザだけで動くシンプルなアラームアプリです。HTML / CSS / バニラ JS のみで構築しており、サーバーやビルドツールは不要です。

## 機能

- 現在時刻の表示
- アラームの追加（時刻 + ラベル）
- アラームの有効 / 無効切り替え
- アラームの削除
- 設定内容は `localStorage` に保存
- 指定時刻になると Web Audio API でビープ音を鳴らし、停止ボタンで停止

## 使い方

1. `index.html` をブラウザで開く
2. アラーム時刻を入力して「追加」
3. 時間になるとオーバーレイが表示され、音が鳴ります
4. 「停止」を押して止めます

## ファイル構成

- `index.html` … マークアップ
- `style.css` … スタイル
- `app.js` … 時計とアラームのロジック
