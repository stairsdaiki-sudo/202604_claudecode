# こころより | 悩み相談サービス LP

「話すことで、心が軽くなる。」をコンセプトに、共感と傾聴を届ける悩み相談サービスのランディングページです。HTML / CSS のみで構築しており、サーバーやビルドツールは不要です。

## デザイン

- **ベース**: 純白（#FFFFFF）/ 薄クリーム（#FAF7F2）
- **アクセントカラー**: 温かみのあるベージュ・タン（#C9A57B / #A07851）
- **タイポグラフィ**: Shippori Mincho（見出し）+ Noto Sans JP（本文）
- **トンマナ**: 朝の柔らかな光、自然素材、リッチでナチュラル

## 構成

- ヒーロー（メインビジュアル + キャッチコピー + CTA + 4 特徴 + タグライン）
- こんなお悩みありませんか？（6 ケース）
- 私たちの約束（共感と傾聴）
- 経験豊富な相談員（4 名のプロフィール）
- ご利用の流れ（4 ステップ）
- 料金プラン（3 プラン）
- お客様の声（★評価 + アバター付き）
- よくあるご質問
- お問い合わせフォーム（SSL 対応）
- フッター + 固定 CTA

## 使い方

`index.html` をブラウザで開くだけで表示されます。

### ファーストビュー写真の差し替え（推奨）

ファーストビューのメイン写真は `images/hero.jpg` から読み込まれます。
お手元の写真（クリーム色のセーターを着た女性が、柔らかな自然光の入る室内で
コーヒーカップを片手にくつろいでいる、暖かいベージュ系のもの）を
**`images/hero.jpg`** というファイル名で配置してください。

写真がない場合は `hero-illustration.svg`（イラスト）が
自動的にフォールバックとして表示されます。

## ファイル構成

- `index.html` … マークアップ
- `style.css` … スタイル
- `hero-illustration.svg` … メインビジュアルのフォールバックイラスト
- `images/hero.jpg` … メインビジュアル写真（要配置）
- `images/README.md` … 画像配置ガイド
