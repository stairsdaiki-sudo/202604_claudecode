# ランダムポケモン

ボタンをクリックするとランダムなポケモンが表示される、ブラウザ完結のシンプルな Web アプリです。HTML / CSS / バニラ JS のみで動作し、ビルドツールやサーバーは不要です。

## 機能

- 「ランダムに表示！」ボタンをクリックすると、無作為に 1 体のポケモンを取得して表示
- 公式アートワーク画像、英名 / 日本語名、図鑑番号、タイプ、身長、体重、とくせいを表示
- データは [PokeAPI](https://pokeapi.co/docs/v2) から取得

## 使い方

1. `index.html` をブラウザで開く
2. 「ランダムに表示！」を押すと、ランダムなポケモンの情報が表示されます
3. 何度でも押して別のポケモンを探せます

## ファイル構成

- `index.html` … マークアップ
- `style.css` … スタイル
- `app.js` … PokeAPI からの取得と描画ロジック
