# 画像ディレクトリ

## hero.jpg（必須）

ファーストビューに使用するメイン写真です。リファレンスと同じく、
以下のような写真を `hero.jpg` というファイル名でこのディレクトリに配置してください。

- 推奨サイズ: 1200×1200px 程度（正方形に近い）
- 推奨内容: クリーム色のセーターを着た女性が、
  柔らかな自然光の入る室内で、コーヒーカップを片手に
  穏やかに微笑んでいる/物思いにふけっている様子
- 全体のトーン: 暖かみのあるベージュ・クリーム系

写真がない場合は SVG イラスト（`hero-illustration.svg`）が
自動的にフォールバックとして表示されます。
