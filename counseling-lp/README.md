# 悩み相談LP（MVP / テストマーケティング用）

共感・傾聴を提供する悩み相談サービスのファーストビューLPです。
ナチュラル・ベージュ基調・柔らかい世界観で、安心感と話しかけやすさを重視しています。

## 開く

`counseling-lp/index.html` をブラウザで直接開くだけで動作します。
HTML / CSS のみの 1 ファイル構成（フォントは Google Fonts、画像は Unsplash）。

## 構成

- ファーストビュー（左：コピー＋CTA / 右：人物写真）
- 波型ディバイダ
- 4つの安心訴求アイコン
- クロージングメッセージ

## デザイン方針

- メインカラー: 淡いベージュ `#E8D5C4`
- 背景: アイボリー `#FBF6EE`
- アクセント: くすみオレンジ `#C98A5F`
- 文字: ダークブラウン `#4A3A30`
- 見出し: Noto Serif JP（明朝）/ 本文: Noto Sans JP
- 余白広め・低彩度・borderは極力使わずソフトなshadowのみ
